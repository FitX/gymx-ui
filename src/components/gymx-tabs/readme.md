Tabs are automatically activated and their panel is displayed when they receive focus.

## Keyboard Interactions

| **Command**           | **Description**                                                                                                  |
|-----------------------| ---------------------------------------------------------------------------------------------------------------- |
| <kbd>ArrowRight</kbd> | Moves focus to the next tab. If the last tab is focused, it wraps around to the first tab.                       |
| <kbd>ArrowLeft</kbd>  | Moves focus to the previous tab. If the first tab is focused, it wraps around to the last tab.                   |
| <kbd>Home</kbd>       | Moves focus to the first tab in the list.                                                                        |
| <kbd>End</kbd>        | Moves focus to the last tab in the list.                                                                         |
| <kbd>Tab</kbd>        | Moves focus from the active tab to the associated tab panel.                                                     |
| **TabPanel**          |                                                                                                                  |
| <kbd>Tab</kbd>        | Moves focus from the tab panel to the next interactive element outside the tab component.                        |

## Interaction Flow

1. **Initial Focus:**
   - When the component is mounted and the component is focused, the currently selected tab receives the focus

2. **Keyboard Navigation:**
   - Use the <kbd>ArrowRight</kbd> and <kbd>ArrowLeft</kbd> keys to navigate between tabs. Focus moves from the current tab to the next or previous tab, and the tab panel's content updates accordingly.
   - The <kbd>Home</kbd> key moves focus to the first tab, and the <kbd>End</kbd> key moves focus to the last tab.
   - When the last tab is focused and <kbd>ArrowRight</kbd> is pressed, focus wraps to the first tab, and similarly, pressing <kbd>ArrowLeft</kbd> on the first tab moves focus to the last tab.

3. **Focus Management:**
  - After selecting a tab, press <kbd>Tab</kbd> to move focus to the associated tab panel.

4. **ARIA Attributes:**
  - Tabs have the `aria-selected` and `aria-controls` attributes to indicate their selected state and association with the corresponding tab panel.
  - Tab panels have the `aria-labelledby` attribute to reference the corresponding tab.

## ARIA Compliance

- The component is ARIA-compliant with appropriate `role="tablist"`, `role="tab"`, and `role="tabpanel"` roles.
- Custom IDs are generated for tabs if not provided. These IDs are based on a provided `id` attribute or default to a unique identifier generated by the component.
